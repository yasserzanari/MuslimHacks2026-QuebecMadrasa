# Positionnement et modèle économique — Madrasa Québec

## Résumé pour les juges

Madrasa Québec ne vend pas seulement des contenus : la plateforme réduit le travail répétitif autour de l’apprentissage, tout en gardant les décisions pédagogiques et les évaluations officielles sous contrôle humain.

À montrer :

1. un tuteur crée ou adapte une activité avec l’aide de l’IA;
2. l’élève reçoit une explication graduée et une pratique adaptée;
3. une copie est pré-corrigée, mais le tuteur valide la rétroaction;
4. le tuteur voit une synthèse de groupe plutôt que 50 suivis manuels dispersés;
5. une famille inscrit son enfant à un groupe extrascolaire local.
6. le calendrier configurable réserve les transitions de prière et de wudu selon les horaires locaux choisis par la famille.
7. en vision future, un contenu sensible est signalé puis revu par un référent humain; aucune conformité religieuse automatique n’est promise.

## Niveaux de preuve

| Terme | Signification |
|---|---|
| **Implémenté** | Présent dans le dépôt et utilisable localement. |
| **Démontrable** | Visible dans le prototype, mais mock, local ou non persistant. |
| **Prévu** | Décrit dans la documentation produit, pas encore livré. |
| **Hypothétique** | Hypothèse commerciale ou opérationnelle qui exige un pilote et des mesures. |
