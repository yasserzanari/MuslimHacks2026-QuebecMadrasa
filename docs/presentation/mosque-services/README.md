# Offre mosquée — services B2B/B2B2C

## Positionnement

Madrasa Québec peut devenir l’infrastructure numérique d’une mosquée qui accompagne des familles : administration, groupes, tuteurs, activités, apprentissage et soutien financier dans un espace contrôlé. La mosquée paie ou subventionne le service; les familles et élèves en bénéficient; les tuteurs restent responsables des décisions pédagogiques.

## Statuts à utiliser devant les juges

- **Démontrable :** écrans et API locales du prototype.
- **Prévu :** service décrit dans le produit mais non livré.
- **Hypothèse :** prix, revenus, ratio d’élèves, économies et adoption à tester.

## Règle de crédibilité

Ne pas promettre une automatisation complète, un revenu garanti pour les tuteurs, une capacité fixe par tuteur ou une conformité religieuse/scolaire automatique. Montrer ce qui fonctionne, puis expliquer le pilote qui validera le reste.
